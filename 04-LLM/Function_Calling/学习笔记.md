# Function Calling 复习入口

本目录目前没有独立代码；已实现的工具调用位于 `02-Python-Project/AI-ChatBot/main.py`。

## 核心流程

提供工具说明 → 模型返回名称与参数 → Python 执行工具 → 将结果交回模型 → 获取回答。模型产生调用请求，真正执行本地函数的是应用代码。

参数说明与 Python 实现需要对应；收到 JSON 参数后还应检查类型和允许的工具名称。一次响应可能包含多个调用，不能只假设永远只有第一个。

协议细节见 [OpenAI 官方 Function Calling 文档](https://developers.openai.com/api/docs/guides/function-calling)。本仓库现行实现使用 Chat Completions 风格的工具定义和消息，阅读其他接口示例时应区分结构。
